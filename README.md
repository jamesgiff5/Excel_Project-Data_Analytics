# My Excel Data Analytics Projects

This repository showcases two Excel projects I completed while transitioning into data analytics. Each project highlights different Excel skills, including formulas and functions, data validation, charts, PivotTables, Power Query, and DAX. These were built as part of [Luke Barousse’s Excel for Data Analytics course](https://lukebarousse.com/) and demonstrate key capabilities relevant to data analyst roles.

---

## Project 1: Salary Dashboard  
This dashboard helps users explore salary data across different job titles, making it easy to see if they’re being paid fairly. It was built with core Excel tools like formulas, data validation, and charts for a clean and interactive experience.
